# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Reproducible valid and invalid CSV datasets executed by CI.

## [1.0.0] - 2026-10-09

### Added

- JSON-schema-driven CSV validation.
- Required, type, range, length, regex, enum, and uniqueness rules.
- UTF-8 BOM, duplicate-header, and malformed-row handling.
- Human-readable and JSON reports with stable exit codes.
- Automated tests and a Python-version CI matrix.
- Contributor, safety, and usage documentation.
