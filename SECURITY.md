# Security Policy

## Supported Version

Security fixes are applied to the latest release and the `main` branch.

## Reporting a Vulnerability

Never upload customer CSV files, personal information, credentials, or private
validation reports to a public issue. Use GitHub's **Report a vulnerability**
option when available. Otherwise, open a minimal issue requesting a private
contact channel without including sensitive details.

Include the affected version, impact, and a reproduction using synthetic data.
Reports should demonstrate the behavior without exposing real records.
